# Layout-Design-Assignment

Project Description

Projekt ten powstał w ramach zadania z projektowania układu wizualnego. Jest to podstrona portfolio, na której pokazuję swoje miniaturki na YouTube i mogę przyjmować zamówienia.

Użyte elementy

Kompozycja: Rule of Thirds i Golden Ratio (spirala Fibonacciego)
Kolory: czarny, biały, szary i czerwony jako kolor akcentu
Fonty: League Gothic (nagłówki, menu) i Manrope (tekst opisowy), oba na licencji SIL Open Font License

Technical Information

Software: [Photoshop]
Resolution: [1440 × 1080]
Format: PNG / JPG

Pliki projektu

Stronę.psd – główny plik projektu
Stronę.png – gotowy układ strony
Stronę_GoldenRatio.jpg – układ z nakładką spirali Fibonacciego
Stronę_RuleOfThirds.jpg – układ z nakładką reguły trzecich
